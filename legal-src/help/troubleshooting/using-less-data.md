title: Using less data
summary: Calls, Prayer Rooms and media are the biggest users of mobile data.
keywords: data usage, mobile data, save data, data plan
order: 3
---

If you're mindful of your mobile data plan, the main things to know are:

- **Calls and Prayer Rooms** need a working internet connection and will use mobile data if you're not on Wi-Fi — these are usually the heaviest part of your data use on InterChat, especially video calls or longer Prayer Room sessions.
- **Photos, videos and voice notes** you send or receive also use data, more so for video than text or voice notes.
- **Connecting to Wi-Fi** whenever it's available is the simplest way to cut down your mobile data use, particularly before a call or a Prayer Room you know will run long.

If you're consistently going over your data plan, it's worth checking your phone's own data usage settings to see which apps (including InterChat) are using the most, so you know where to adjust your habits.
